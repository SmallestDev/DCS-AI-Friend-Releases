# DCS AI Friend — Releases

DCS World **Pretense Syria** 용 한국어/영어 음성 AI 편대 (JARVIS · FRIDAY · ULTRON).
내가 편대장이 되고, 세 AI 편대원이 각자 실제 AI 항공기(또는 지상 차량)를 몰고 따라옵니다.

## 받기
[Releases](../../releases/latest) 에서 최신 `DCS_AI_Friend_v<버전>.zip` 을 받아 압축을 풀고 `설치방법.txt` 를 따라 하세요.

- 프로그램(`DCS_AI_Friend.exe`) + 미션(`Pretense_syria_unu_1.7.2_AI_Friend.miz`) + 설명서(`README_KO.md`)
- 필요: DCS World, Pretense Syria 캠페인, (지상 차량을 몰려면) Combined Arms
- OpenAI 음성 인식을 쓰려면 프로그램 폴더의 `.env` 에 `OPENAI_API_KEY=...` (없으면 PC 안의 음성 인식만 사용)

이 저장소에는 배포 파일만 올라옵니다. 미션 안의 Pretense 스크립트는 원작자(Dzsekeb)의 것입니다.
