# DCS AI Friend - Releases

AI wingman flight (JARVIS, FRIDAY, ULTRON) with Korean / English voice control for DCS World **Pretense Syria**.
You lead the flight; each AI wingman flies a real AI aircraft (or ground vehicle) and follows your orders.

## Download
Get the latest `DCS_AI_Friend_v<version>.zip` from [Releases](../../releases/latest), unzip it and follow `설치방법.txt` (install guide, Korean).

- Program (`DCS_AI_Friend.exe`) + mission (`Pretense_syria_unu_1.7.2_AI_Friend.miz`) + manual (`README_KO.md`)
- Requires DCS World and the Pretense Syria campaign; Combined Arms to drive ground vehicles
- For OpenAI speech recognition put `OPENAI_API_KEY=...` in a `.env` file in the program folder (without it only on-PC recognition is used)

This repository only holds release files. The Pretense scripts inside the mission belong to their author (Dzsekeb).
